# MathBoard: приложение для Android + постоянная ссылка для учеников из любого города

Логика доски, `engine.py`, `index.html` и уроки `.mth` **не менялись**.
В `server.py` добавлены 3 строки: порт и ключ учителя берутся из переменных окружения (`PORT`, `TEACHER_KEY`),
а если ключ задан, сервер не запускает туннели. Без этих переменных всё работает как раньше (`start.bat`).

## Как это устроено
- **Сервер** (`server.py`) живёт в интернете на постоянном адресе вида `https://mathboard-xxx.fly.dev`. Компьютер включать не надо.
- **Приложение Android** — оболочка над этим адресом. Ученик нажал на значок и сразу попал в урок.
- **Учитель** заходит в то же приложение с ключом (один раз вводит, дальше запоминается) или с компьютера по `https://ваш-адрес/?key=КЛЮЧ`.
- Ученик без приложения тоже может просто открыть ссылку в браузере.

## Шаг 1. Сервер в интернете (один раз)
### Вариант A: Fly.io (рекомендую, не засыпает, около 2–4 $/мес, нужна карта)
```
fly auth signup            # или fly auth login
fly launch --no-deploy --copy-config     # имя приложения: поменяйте mathboard-CHANGEME на своё в fly.toml
fly secrets set TEACHER_KEY=ВашДлинныйСекретныйКлюч123
fly deploy
```
Адрес будет `https://<имя>.fly.dev`. Ключ придумайте длинный, это ваш пароль учителя.

### Вариант B: Render.com (бесплатно, без карты, но сервер засыпает через 15 мин простоя)
Загрузите проект на GitHub, затем на render.com: New → Blueprint → выберите репозиторий (файл `render.yaml` уже есть).
Ключ учителя: Dashboard → Environment → `TEACHER_KEY`.
Минус: если никто не заходил 15 минут, первый вход ждёт около минуты. Откройте приложение за 2 минуты до урока.

Выбрать урок: переменная `LESSON` (по умолчанию `monomials.mth`; на Fly поменяйте в `fly.toml` и сделайте `fly deploy`).
Внутри урока кнопка «reload» у учителя перечитывает файл, как и раньше.

## Шаг 2. Собрать APK (ничего устанавливать не нужно)
1. Откройте `android/gradle.properties` и впишите свой адрес: `serverUrl=https://ваш-адрес` (https, без `/` в конце).
2. Создайте на GitHub **публичный** репозиторий и загрузите туда всю эту папку (ключ учителя в репозиторий НЕ кладите).
3. Вкладка **Actions** → «Build Android APK» → **Run workflow**. Через 3–6 минут готово.
4. Постоянная ссылка на скачивание для учеников:
   `https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПО/releases/download/latest/MathBoard.apk`
   Её и кидаете ученикам. Они скачивают APK и разрешают «установку из неизвестных источников» (Android спросит сам).

Если поменяете адрес сервера, пересоберите APK (повторите пункт 3).

## Шаг 3. Урок
- Ученики: открывают приложение MathBoard (или ссылку `https://ваш-адрес/` в браузере).
- Вы: долгое нажатие на значок MathBoard → **«Я учитель»** → вводите ключ. Или на компьютере: `https://ваш-адрес/?key=КЛЮЧ`.
- Вернуть телефон в режим ученика: «Я учитель» → «Я ученик».

## Важно знать
- Состояние доски хранится в памяти сервера, поэтому сервер должен работать в **одном** экземпляре (в `fly.toml` так и настроено).
- Ссылка `https://ваш-адрес/` в мессенджере открывается в браузере. В приложении она откроется, только если в настройках приложения включить «Открывать поддерживаемые ссылки». Надёжнее: ученик один раз ставит приложение и дальше запускает его с экрана.
- APK собирается как debug-версия (подходит для раздачи напрямую, в Google Play в таком виде не загрузить).
- Android 8.0 и новее.
